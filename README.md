# 간단하게 당뇨병 진단해보기 앱

## 검사 API

- `POST /diagnosis`는 나이, 몸무게, 키, 혈당, 임신 횟수를 받습니다.
- 서버에서 34세 이하는 `check_age_34_or_under`, 35세 이상은 `check_age_over_34`에 전체 입력을 전달하고, 함수 반환값을 `result`로 응답합니다.
- 두 경로 모두 임신 횟수, BMI, 혈당을 입력받습니다.
- BMI 데이터는 [18.5, 23.0, 25.0, 30.0, 35.0] 구간을 기준으로 ['저체중', '정상', '비만 전단계', '1단계 비만', '2단계 비만', '3단계 비만'] 데이터로 원 핫 인코딩됩니다. 이후 BMI 수치 데이터는 사라집니다.
- 마찬가지로 혈당 수치도 [70, 100, 126] 구간을 기준으로 ['혈당_저혈당', '혈당_정상', '혈당_당뇨병 전단계', '혈당_당뇨병']으로 나눕니다.

`server/artifacts`에 연령대별 SVC와 학습된 스케일러를 보관합니다.
34세 이하는 `MinMaxScaler`, 35세 이상은 `StandardScaler`로
11개 특성을 변환한 뒤 해당 연령대의 SVC로 예측합니다.
모델 반환값은 `0`이면 정상, `1`이면 당뇨로 표시합니다.
